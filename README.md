# Pizza-Sales
🚀 Excited to share my latest Business Intelligence project: Pizza Sales Analytics Dashboard!

This project was developed using SQL and Power BI to analyze pizza sales data and generate meaningful business insights through interactive dashboards and KPI reporting.

🔹 Project Highlights:
• Total Revenue & Order Analysis
• Average Order Value Tracking
• Sales Trend Analysis (Daily & Monthly)
• Top & Bottom Performing Pizzas
• Pizza Category & Size-wise Performance
• Interactive Dashboard using DAX Measures

🛠 Tools & Technologies:
SQL Server | Power BI | DAX | Power Query | Excel

📊 Key Business Insights:
• Large-sized pizzas generated the highest revenue
• Weekend sales were higher compared to weekdays
• Peak customer activity occurred during evening hours
• Classic pizza category contributed maximum overall sales
• Top-selling pizzas drove a significant portion of total revenue

This project helped strengthen my skills in SQL querying, data analysis, KPI development, data modeling, and dashboard visualization while gaining hands-on experience in Business Intelligence reporting.
